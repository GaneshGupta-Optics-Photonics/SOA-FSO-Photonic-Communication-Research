# Gamma-Gamma Irradiance Distribution Model

## Overview

The Gamma-Gamma distribution is widely used to model optical intensity fluctuations in turbulent FSO communication channels.

It considers atmospheric turbulence as the combined effect of:

1. Large-scale turbulent eddies.
2. Small-scale turbulent eddies.

The received irradiance is expressed as:

\[ I=I_0.X.Y\]

where:

- \(I_0\) is the average transmitted irradiance.
- \(X\) represents large-scale turbulence effects.
- \(Y\) represents small-scale turbulence effects.

---

# Probability Density Function

The Gamma-Gamma probability density function is:

\[
p(I)=
\frac{2(\alpha\beta)^{(\alpha+\beta)/2}}
{\Gamma(\alpha)\Gamma(\beta)}
I^{(\alpha+\beta)/2-1}
K_{\alpha-\beta}
(2\sqrt{\alpha\beta I})
\]

where:

- \(\alpha\) is the large-scale turbulence parameter.
- \(\beta\) is the small-scale turbulence parameter.
- \(K_n\) is the modified Bessel function.

---

# Gamma-Gamma Parameters

The parameters are obtained from the Rytov variance.

Large-scale parameter:

\[
\alpha=
\left[
e^{\frac{0.49\sigma_R^2}
{(1+1.11\sigma_R^{12/5})^{7/6}}}-1
\right]^{-1}
\]

Small-scale parameter:

\[
\beta=
\left[
e^{\frac{0.51\sigma_R^2}
{(1+0.69\sigma_R^{12/5})^{5/6}}}-1
\right]^{-1}
\]

---

# Application

The generated turbulence channel coefficient is used to calculate:

- received optical power fluctuations
- scintillation index
- SNR degradation
- amplifier performance crossover
